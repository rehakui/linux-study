## 実践内容

### cat

```bash
cat test/test.txt
```

- テキストファイルの内容を表示
- パスを間違えると `No such file or directory` になることを確認

---

### wc

```bash
wc test/test.txt
```

出力例

```text
1 2 13 test/test.txt
```

確認できる情報

- 行数
- 単語数
- バイト数

---

### sort

```bash
sort test/test.txt
sort -n test/test.txt
```

- テキストを並び替えるコマンド
- `-n` オプションで数値としてソートできることを学習

今回はサンプルデータで動作を確認した。

---

### vim

`test/test.txt` を編集し、内容を変更しながら `cat` と `sort` の動作を確認した。

---

## 学んだこと

- `cat` はファイル内容を素早く確認できる。
- `wc` は行数・単語数・文字数（バイト数）の確認に便利。
- `sort` は文字列だけでなく数値順にも並び替えられる。
- コマンドを組み合わせることで、テキストファイルの確認や加工を効率よく行える。
