# TIL - 2026-08-25 ネットワーク基礎

## 名前解決まわり

| 項目 | 覚え方 |
|---|---|
| `/etc/nsswitch.conf` | どの順番で調べる？ |
| `/etc/hosts` | 名前とIPを直接書いてある |
| `/etc/resolv.conf` | どのDNSサーバーに聞く？ |
| `host` / `dig` | DNSに聞いて結果を確認する |

## TCP/IPの4階層

| 層 | 何をする？ | 代表例 |
|---|---|---|
| アプリケーション層 | 何をする？ | HTTP、DNS、SMTP |
| トランスポート層 | どうやって届ける？ | TCP、UDP |
| インターネット層 | どこへ届ける？ | IP、ICMP |
| ネットワークインターフェイス層 | 同じネットワーク内でどう届ける？ | Ethernet、MAC |

## よく使うポート番号

| ポート | プロトコル | 用途 |
|---|---|---|
| 20・21 | FTP | ファイル転送 |
| 22 | SSH | 遠隔操作 |
| 25 | SMTP | メール送信 |
| 53 | DNS | 名前解決 |
| 80 | HTTP | Web通信 |
| 443 | HTTPS | 暗号化されたWeb通信 |

## 今日の要点

- 名前解決では、設定ファイルごとの役割を区別する。
- TCP/IPは「何をするか」「どう届けるか」「どこへ届けるか」「同じネットワーク内でどう届けるか」で整理する。
- 代表的なポート番号と用途を対応させて覚える。
