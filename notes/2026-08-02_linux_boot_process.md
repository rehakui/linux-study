# TIL - Linuxの起動の流れ

## 今日学んだこと

Linuxが起動するまでの大まかな流れを学習した。

BIOS / UEFI
↓
ブートローダ
↓
カーネル
↓
init

## 起動の流れ

### 1. BIOS / UEFI

コンピュータの電源を入れると、最初にBIOSまたはUEFIが動作する。

ハードウェアを初期化し、起動するデバイスを探す。

### 2. ブートローダ

BIOS / UEFIからブートローダが読み込まれる。

LinuxではGRUBなどが使われ、起動するカーネルを選択してメモリへ読み込む。

### 3. カーネル

Linuxカーネルが起動する。

CPU、メモリ、デバイスなどを管理し、Linuxシステムを動作させるための準備を行う。

### 4. init

カーネルの起動後、最初のプロセスとしてinitシステムが起動する。

現在のLinuxでは `systemd` が使われることが多い。

## 覚えておく流れ

`BIOS / UEFI → ブートローダ → カーネル → init`

まずはこの順番をしっかり覚える。
