## 標準入出力

```bash
>       # 標準出力 → ファイル
2>      # 標準エラー出力 → ファイル
<       # ファイル → 標準入力
|       # コマンドの標準出力 → 次のコマンドの標準入力
```

例：

```bash
grep "error" log.txt | sort
```

`grep` の検索結果を `sort` の標準入力として渡す。

## 今日覚えたコマンド・オプション

### xargs

標準入力をコマンドの「引数」に変換する。

```bash
xargs
```

### sed

```bash
sed 's/old/new/'    # 文字列を置換
sed 'y/abc/ABC/'    # 文字単位で変換
sed '/text/d'       # 条件に一致した行を削除
```

* `s` = substitute（置換）
* `y` = 文字単位の変換
* `d` = delete（削除）

### grep

```bash
grep -v "error" file.txt
```

`-v` は条件を反転し、**一致しない行**を表示する。

### gzip

```bash
gzip -d file.gz
```

* `-d` = decompress（解凍）
* `-c` = 結果を標準出力へ出力

### tar

```bash
tar -c
tar -x
```

* `-c` = create（アーカイブ作成）
* `-x` = extract（アーカイブ展開）

### cpio

```bash
cpio -o
cpio -i
```

* `-o` = アーカイブを作成
* `-i` = アーカイブからファイルを取り出す

### dd

```bash
dd if=input.txt of=output.txt
```

* `if=` = input file（入力元）
* `of=` = output file（出力先）

## vi

`vi` ではモードを切り替えて操作する。

* **ノーマルモード（コマンドモード）**：カーソル移動や各種操作
* **挿入モード（入力モード）**：文字を入力する

```text
:w      保存
:wq     保存して終了
```
